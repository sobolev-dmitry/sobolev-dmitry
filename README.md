## 💼 Проекты

- **[Портфолио](https://sobolev-dmitry.github.io/)** — мой личный сайт с нуля на HTML/CSS/JS.  
  **Ключевое:** BEM‑архитектура, семантическая вёрстка, кастомные шрифты Manrope, SVG‑иконки, адаптив под узкие экраны (от 375px). **Есть рабочая контактная форма на Web3Forms** — сообщения приходят в панель Submissions, настроена валидация полей и UX‑состояния (успех/ошибка). Проект активно поддерживается.

- **[Stellar Burgers](https://github.com/sobolev-dmitry/stellar-burgers)** — конструктор бургера с авторизацией и лентой заказов.  
  **Ключевое:** работа с состоянием и формами, валидация ввода, отображение ленты заказов, обработка UI‑состояний (загрузка, ошибка, успех). Проект демонстрирует работу с динамическим контентом и интеграцию логики в интерфейс.

- **[Web‑Larёк](https://github.com/sobolev-dmitry/weblarek)** — интернет‑магазин на Vite 7 + TypeScript.  
  **Ключевое:** доработал функциональность — корзина, модальные окна, оформление заказа с отправкой на сервер. Приложение построено по архитектуре MVP, проект описан в README. Настроена сборка и деплой на GitHub Pages.

- **[Топ Скоуп](https://github.com/sobolev-dmitry/top-scope-landing)** — лендинг коворкинга.  
  **Ключевое:** разработал собственный UI‑кит для проекта (кнопки, инпуты, отступы, типографика), семантическая разметка и логическая структура блоков, дизайн и реализация формы «Записаться на пробный день» с валидацией и UX‑состояниями. Полный цикл от макета в Figma до реализации.

- **[Сложно сосредоточиться](https://github.com/sobolev-dmitry/slozhno-sosredotochitsya-fd)** — адаптивный сайт с автоматическим переключением тем.  
  **Ключевое:** определение системной темы через `prefers-color-scheme`, единый набор CSS‑переменных для светлой и тёмной тем, ручное переключение в шапке без перезагрузки страницы, согласованные стили для всех состояний элементов. Проект — пример того, как я подхожу к архитектуре стилей и доступности.
